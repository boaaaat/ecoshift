# Expedition chiseled rock

Superseded modeling source. The active campaign uses the smooth textured `../environment/weathered-boulder/WeatheredBoulder.blend` and its saved PBR template in `src/ServerStorage/ArtAssets.rbxm`. This older project remains saved for reference and is not used by current environment generation.

Original EcoShift low-poly mesh, authored September 20, 2026 in Blender 5.2 LTS. No downloaded geometry or paid assets were used for this rock.

- `Expedition_ChiseledRock.blend`: editable source scene.
- `Expedition_ChiseledRock.fbx`: selected rock mesh export; 24 vertices and 44 triangles.
- `geometry.json`: exported vertex and triangle data for reference.

The shape was made through Blender's UI using bevel, flattening and vertex randomization. Blender scripting handled naming, material, ground-origin adjustment, saving and export. The source scene retains Blender's camera and light; the FBX contains only the selected rock.

Originally imported into Roblox under Revolutionary Raft Riders, group 34468779. Former mesh asset: `rbxassetid://130250902917245`.

The former untextured geometry and session-only import were replaced during the detail pass.
